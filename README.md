# ReactNativeFilmesApp

### Repositório destinado para a realização da seguinte atividade: 

Criar um aplicativo em React Native que consome uma API REST pública para listar, pesquisar e exibir detalhes de filmes.

# Passo a passo para rodar o projeto: 

### Primeiro passo: Clonar o repositório

### git clone https://github.com/Renan-Parise/ReactNativeFilmesApp

### Segundo passo: Entrar na pasta raiz do projeto, com o seguinte comando: 

### cd ReactNativeFilmesApp

### Terceiro passo: Precisa instalar as dependências

### yarn

### yarn expo start

### Quarto passo: Rodar o projeto com o seguinte comando:

### npm start
